# Version 1.1.0 (October 6, 2025)

- Release of the new CCSD(cT) algorithm, see documentation for
  `PerturbativeTriples` in the manual.
- Implementation of an interface for the [MRCC](https://www.mrcc.hu/MRCC/manual/pdf/manual.pdf) program.
  The new algorithm is called `MRCCReader`, consult the documentation for more details.
- New CMAKE based build system. The old ad-hoc Make build system is considered deprecated.
- Several internal improvements.
